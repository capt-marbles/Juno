# Naming

The project started as **JcodeCP**, shorthand for “Jcode Control Panel.”

It is now called **Juno**.

Why Juno:

- Short, memorable, and not tied to a single host agent.
- Still fits the control-panel idea: a mission-control companion for agent work.
- Leaves room for Jcode-native integration and companion modes for Claude Code-style workflows.

Working tagline:

> Juno is a terminal mission control panel for agent work.
